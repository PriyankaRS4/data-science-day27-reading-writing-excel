# Reading and Writing Excel Data

## Description
Read Excel worksheets using Pandas, inspect their structure, perform simple transformations, and export the results.

## Objective
Learn to work with Excel data commonly used in business and data science environments.

## Tools
- Python
- Pandas
- Jupyter Notebook
- OpenPyXL

## Deliverables
- Excel data loading example
- Basic data cleaning and transformation
- Processed Excel output file

## Hints / Mini Guide
- Use read_excel()
- Specify a sheet when required
- Use to_excel() to export results

## Suggested Datasets
- Superstore Dataset
- Employee Dataset

## Interview Questions
- How do you read an Excel file using Pandas?
- What library is commonly used as an Excel engine?
- What is the difference between CSV and Excel files?
